# 碧侯教會 室內裝修工程 — 工程安排建議書

> 對應文件：工程報價單（NT$16,729,761）、施工圖、天花/剖面大樣、3D 設計簡報
> 建築規模：3 層樓 + 頂樓加蓋，約 549 坪；多功能教會（主/副會堂、主日學教室、寢室、餐廳廚房、辦公）

---

## 摘要：最該優先處理的 5 件事

1. **先封口「合約未含 4 大工項」**：泥作防水（尚未評估）、地坪、空調、油漆——這 4 項都壓在關鍵路徑或界面上，未定義會直接拖垮全案。**開工前務必界定範圍、廠商與費用。**
2. **長交期項目立刻發包**：石材、系統櫃（56 被褥櫃+床組）、廠製門、頂樓鋼構、設備。偏遠工地（碧侯）運輸與備料須提前 4～8 週。
3. **以「2 樓主會堂」為核心排程**：它是鷹架＋天花＋石材＋木作疊在同一空間的關鍵路徑，集中資源、嚴格管控工序交接。
4. **鷹架一次到位**：高處工項（天花、上部石材、油漆、燈具）排在同一鷹架週期完成，避免重複搭拆。
5. **天花封板前完成消防/空調整合**：這是不可逆的隱蔽工程界面，錯過要拆天花重做。

## 一、先釐清「合約未含 / 待評估」工項（風險第一）

報價單中以下工項**未含或尚未評估**，但每一項都會卡到施工順序，必須在開工前定案：

| 工項 | 報價狀態 | 為何是風險 | 建議 |
|---|---|---|---|
| **泥作 / 防水** | 尚未評估 | 濕區（各層廁所、廚房、傳道房衛浴、新增水槽）防水、RC 開孔收邊、地坪整平都靠它；**石材/磁磚/地坪都要等它** | 立即現勘估價，排在拆除後、天花前；防水須**試水**驗證 |
| **地坪工程** | 未含 | 接待大廳、通廊等地坪完成面未定，影響石材踢腳收頭高程與所有櫃體立面尺寸 | 確認是誰施作、材質與完成面標高（FL±0） |
| **空調工程** | 未含 | 室內外機、冷媒/排水管、出風口多在天花內；**一定要在輕鋼架封板前定位** | 先決定空調廠商與點位，納入天花整合會議 |
| **油漆工程** | 未含 | 介於木作之後、燈具/細清之前的關鍵收尾；漏排會讓後段全部卡住 | 由業主自辦或追加，務必排入第 23 項時段 |

> 另：報價多項註明「**待確認 / 待評估 / 取消**」（如電視、投影機、洗衣機、淋浴門、影印機、二三樓玻璃門因不符法規暫取消、大東/玻璃防火門待評估、廚房設備需求）。建議**開工前彙整成一份「待確認清單」逐項結案**，並以追加減正式變更，避免現場停工等指示或事後重做。

## 二、長交期備料與發包（保護工期）

偏遠工地（報價單可見「偏遠地區運送」字樣）＋客製量大，**備料是頭號進度風險**。建議簽約後立即下單：

| 項目 | 為何長交期 | 動作 |
|---|---|---|
| **石材**（雅典白花崗岩 1,285 才壁面+664 才地坪、小雕刻白） | 進口/加工/水磨、量大 | 先放樣→開料→排版，預留 4～6 週 |
| **系統櫃**（56 組被褥櫃、床組、聖器室/吧台/大廳櫃） | 數量龐大、需工廠生產 | 確認板材/五金後即下單，分批進場 |
| **廠製門 / 木作門窗** | 工廠製作 | 門表確認後發包，到貨對應第 16 項 |
| **頂樓鋼構** | 需放樣、噴砂、優麗漆、吊裝排程 | 確認結構圖→工廠製作→安排吊車 |
| **設備**（立式烘碗機 VVR-180、飲水機、機櫃、各式扇） | 部分需訂貨 | 型號確認後下單，對應收尾期 |

**運輸建議**：偏遠工地採「集中、分階段」進料，搭配吊裝/搬運計畫；大型件（床組、櫃體、石材、鋼構）排定吊裝日，避免零星車次與二次搬運成本。

## 三、施工順序與流水作業（Sequence）

### 標準工序（單一空間）
```
保護/鷹架 → 拆除 → 泥作打底/防水 → 水電配管配線 → 輕鋼架天花骨架
→（消防/空調天花內整合）→ 天花封板 → 木作底 → 石材/磁磚 → 木作面/油漆
→ 系統櫃/櫃體 → 人造石/玻璃 → 燈具/設備 → 窗簾/家飾 → 清潔 → 驗收
```

### 分樓層流水（壓縮工期的關鍵）
- **濕程/水電/天花**：建議**由下而上（1F→2F→3F）**逐層推進，前一樓完成即接續，後方樓層同步展開。
- **完成面/收尾（油漆後）**：建議**由上而下（3F→1F）**退場，保護已完成的下層樓面，最後交 1F 大廳門面。
- 各工班以**「3 週前置看板（3-week look-ahead）」**滾動安排，避免同一空間多工種搶位。

## 四、主會堂（2F）— 全案關鍵空間的專案管理

主會堂同時牽涉**鷹架（6.8M 滿堂架/活動架）＋ 80 坪礦纖天花 ＋ 花崗岩壁面(消光)/地坪(光面)/講台 ＋ 木作反射板/格柵 ＋ 講桌石材**，是工序最密、最易打架的空間：

1. 鷹架搭設後，**先完成高處**（天花、上部壁面石材、燈具預留），鷹架不拆。
2. 石材壁面屬重工、濕式黏貼，需與木作（反射板、格柵、講台天花）**排定交接界面**，先底後面。
3. 講台是**石材＋木作＋金屬結構**三方交界，務必先做 1:1 放樣與大樣會審（參考剖面圖 B01 系列）。
4. 鷹架退場前做**高處查驗清單**（天花、燈具、石材上緣 1×1 斜角收邊），避免二次搭架。

## 五、隱蔽工程與界面整合（不可逆，最該開會）

| 界面 | 整合重點 |
|---|---|
| **天花內：水電 + 消防 + 空調** | 封板前定案燈具/感應器/廣播/探測器點位與空調管線；消防多為**既有**，延伸/下拉需配合新天花重新定位（報價含閘門/設備下拉延伸工料） |
| **1F 大廳主牆**：FMG 薄磚 + 夾板底 + 石材踢腳 | 依大樣 B01-03，木作底→薄磚→收邊，厚度與收頭先確認 |
| **系統櫃 + 人造石檯面 + 水槽/設備** | 櫃體就位後才能丈量檯面下崁取孔；給排水（明管）位置先定 |
| **木作 + 玻璃/鏡** | 接待大廳柱面明鏡、講台灰鏡、櫃體崁玻璃，預留溝縫尺寸 |
| **防火法規** | 二三樓會堂玻璃門已因法規暫取消、防火門待評估，須確認防火區劃與**消防/室裝簽證**，避免驗收卡關 |

## 六、品質、安全與進度管控

- **每週工地會議 + 月進度查核**：對照本甘特圖追蹤實際進度，落後即啟動趕工或調序。
- **請款綁里程碑**：合約有監管費 10%（代表有監造/PM），建議按里程碑（開工、天花完成、石材完成、櫃體完成、交屋）分期估驗計價。
- **安全**：高架作業（主會堂 6.8M、頂樓吊裝、梯間防墜網）落實安全防護；社區/教會若需部分使用，採**分區圍封**。
- **天候緩衝**：頂樓鋼構為室外作業，雨季須預留緩衝；偏遠運輸亦預留彈性。
- **保護到底**：石材/櫃體完成後加強成品保護，至細清前不拆，降低修補。

## 七、可選的工期優化方向

| 方向 | 作法 | 效益 |
|---|---|---|
| 平行作業 | 頂樓鋼構（室外）與室內泥作/水電同時進行 | 省 3～4 週 |
| 分區提前交付 | 若教會需提早使用，先完成 1F 大廳/餐廳或 2F 主會堂分區點交 | 提前局部啟用 |
| 工班接力 | 水電→天花→木作依樓層接力不空窗 | 壓縮整體工期 |
| 趕工加成留意 | 報價註明：若社區壓縮工時，部分工項有 2.5–4%/0.5hr 誤工加成 | 控管工時規範避免加價 |
