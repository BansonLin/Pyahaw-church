# 碧侯教會 室內裝修工程 — 細部施工順序（涵蓋所有區域）

> 搭配圖檔：[細部施工順序圖.png](細部施工順序圖.png)
> 依「空間類型」歸納，全棟每個房間皆對應一種類型（見文末對照表），不遺漏。
> ①②③… 為該空間內之施工先後；〔整合〕為**封板前不可逆**之隱蔽工程；「‖」表可平行。

## 全棟流水原則（總順序）

```
假設保護 → 拆除(全棟) → 〔頂樓鋼構：室外平行〕
 → 濕程/水電/天花骨架【由下而上 1F→2F→3F】
 → 木作 → 石材 → 油漆 → 系統櫃/床組 → 收尾設備/燈具/玻璃/家飾
 → 清潔【由上而下 3F→1F 退場，保護下層完成面】 → 驗收/交屋
```
- **濕區優先**：每層先做廁所/衛浴防水試水，再展開乾區。
- **會堂最早啟動**：主會堂因鷹架(6.8M)＋80坪天花＋石材最費時，列為各樓層起始重點。
- **同一空間內**：一律「先濕後乾、先上後下、先底後面、先隱蔽後外露」。

## 跨區域排序與依存（排程時的關鍵卡控）

1. **由下而上**做濕程/水電/天花（1F→2F→3F），前樓完成即接續，後樓同步展開。
2. **主會堂(T2)/副堂** 因鷹架與石材最久，**最早**啟動天花與石材；鷹架期間集中完成所有高處工項。
3. **石材集中調度**：T2 會堂壁面/地坪、T3 大廳踢腳、T8 音控室地坪同屬花崗岩，統一放樣/開料/進場，減少車次（偏遠工地）。
4. **系統櫃/床組(T4)** 量大（56 被褥櫃 + 床組），須在寢室完成面(油漆)後分批進場；與金屬床架交接。
5. **完成面由上而下退場清潔**（3F→1F），保護已完工下層；成品保護至細清前不拆。
6. **業主自辦 4 項（泥作防水、地坪、空調、油漆）** 須在對應序位前完成界定：泥作防水(各 T 的②③)、空調(各 T 的〔整合〕)、油漆(各 T 油漆序)、地坪(影響踢腳收頭高程)。
