## 五、關鍵路徑（Critical Path）

```
待確認項目決議 → 長交期下單 → 進場保護/鷹架 → 泥作防水 ┐
                                              水電配管 ┴→ 輕鋼架天花(2F/3F主會堂)
   → 天花內 消防/空調整合 → 木作(講台/壁面/反射板) → 石材壁面(主會堂/副堂)
   → 油漆 → 系統櫃/床組 → 照明/設備 → 粗清+細清 → 驗收/交屋
```

**主會堂（鷹架＋80 坪天花＋花崗岩壁面/地坪/講台＋木作反射板）為全案資源最密集、工序最長之關鍵空間，主導總工期。**
