## 進場波次（依進場順位）

- **W1（6/19~）**：主會堂(鷹架先行)、梯間/通廊(保護)、頂樓鋼構(室外平行)。
- **W2（7/06~）**：1F 全區(廁所/餐廚/大廳/教室/寢室/辦公) 由下而上先啟動。
- **W3（7/13~）**：2F 全區(主會堂續、大廳/教室/辦公/傳道房/廁所)。
- **W4（7/22~）**：3F 全區(副堂/交誼廳/音控/寢室/廁所)。

## 使用方式

1. **縱看**找區域、**橫看**對日期，即知該區某週應進什麼工種。
2. 同一週多區同工種 → 該工班需備足人力或分批；可作為**工班排程與請款估驗**依據。
3. 〔石材〕跨主會堂/副堂/大廳/音控室，**統一放樣開料、分批進場**（偏遠工地降車次）。
4. 〔油漆/空調/泥作防水〕為業主自辦/未含，須於各區對應時點前完成界定，否則該區順延。
5. **退場(▸)由上而下**：3F(11/18)→2F(11/20)→1F(11/24)→梯廊(11/25)，保護已完成樓層。
